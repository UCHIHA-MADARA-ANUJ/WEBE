Theme

Ten panels, twenty files, no animation. Each panel exists twice — once for light, once for dark — and the README switches between them with <picture>. Nothing here moves, loops, or resets, so a screenshot is always the whole design.
Four accents, one per section, drawn from her own artwork. Type is outlined, so it cannot fall back to a different font on someone else's machine.

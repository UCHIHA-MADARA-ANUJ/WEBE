## ◈ Currently building

**DEEP FIELD** — a living atlas of the cosmos with no fixed interface.
35 astronomy objects, 79 typed relations, six structural paradigms, and an engine that picks one for you based on eleven behavioural features it derives in real time. It explains every change it makes, in plain language, with the evidence behind it.

```
constellation  →  you click without reading  →  mosaic
constellation  →  you open one thing and stay →  codex
```
